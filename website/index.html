⌘/ 命令与技能

你在终端里用惯的，一样都不少

Cove 在一个真正的终端里启动你装好的 claude 和 codex。它们自己更新，Cove 不用跟着改。

  • 原版界面和快捷键你看到的就是 CLI 自己画的那一屏，Esc、Ctrl-C、上下键都照旧。
  • 斜杠命令、MCP、hooks、技能CLI 支持什么就是什么，Cove 不拦也不改写。
  • 你的账号和配置用你在终端里登录好的账号，不需要另外的 API key 或订阅。
  • 你的 shell在你的登录 shell 里启动，环境变量和 PATH 都在。

两种用法，你来选

每个会话可以单独选，⇧⌘M 切换。点一下，上面的窗口就换过去。

不管哪种，这几个麻烦都没了

上周那个会话，去哪了

在终端里找旧会话，得 claude --resume 一页页往下翻，Codex 的又在另一处。Cove 把会话按项目列在左边，能搜索、置顶、改名，点一下就接着聊。

⌘K

中文，不用在终端里硬打

候选框跟不上光标，长段落改一个字要拿方向键挪半天。在终端下面加一个 Mac 输入框，选区、撤销、多行、附件和粘贴截图都按 Mac 的习惯，写好了交给 CLI。用不着就关掉。

交给 Claude Code

Claude Code 和 Codex，排在同一列

不用再一个终端标签跑 claude、另一个跑 codex。同一个项目下的会话排在一起，切过去就是各自原本的界面。每个会话前有个小方块：蓝的在干活，橙的在等你，扫一眼就知道该先回哪个。

额度还剩多少，不用敲命令查

其他细节

Git
分支、工作区改动和 PR 检查都在检查器里。PR 功能需要已登录的 gh。
工作树
⇧⌘N 在独立的 Git 工作树里开一个并行的 Claude 会话。
用量
显示各 CLI 实际提供的用量。按 API 价估算的费用不代表订阅的实际支出。
备份
Claude 会话记录在本机备份，可以在设置里关掉。
你的配置
Cove 不改 ~/.claude/settings.json，需要的设置只在启动时用 --settings 叠加。
粘贴图片
截图可以直接粘进输入框，和文件附件一起交给 CLI。

Antigravity（agy）是实验性接入，对话界面暂不支持审批、打断，也不显示恢复前的消息。

安装

先在终端里装好并登录 Claude Code 或 Codex，确认能正常对话。Cove 不附带 CLI、模型或订阅，用的是你自己的登录和配置。

  1. 1

    下载

    下载 .dmg，打开后把 Cove 拖进「应用程序」。也可以下载 ZIP 版本。

    下载 Mac 版
  2. 2

    第一次打开

    这一版只有本地签名，还没经过 Apple 公证，macOS 可能会拦下。试着打开一次后，到「系统设置 → 隐私与安全性」点「仍要打开」。

    Apple 的说明
  3. 3

    选好 CLI

    引导会找到已经装好的 CLI，选一个登录过的。⌘N 选项目文件夹，⌥⌘N 开一个临时会话。

    遇到问题看安装帮助
从源码构建

需要 Xcode，或带 Swift 6 工具链的 Command Line Tools。Intel Mac 可以试试源码构建，目前还没验证过。

git clone https://github.com/huyanxius/Cove.git
cd Cove
scripts/bundle.sh
open build/Cove.app

Make yourself at home.
