Cove's first downloadable preview brings Claude Code and Codex into a native Mac workspace.

## Download and open

- **Apple Silicon · macOS 14+**. Download `Cove-macOS-arm64.dmg`, open it, and drag Cove to Applications. A ZIP is available too.
- Install and sign in to Claude Code or Codex in Terminal first. Cove uses your existing CLI, account, and provider.
- **Not Apple-notarized:** this preview is ad-hoc signed. If blocked on first launch, attempt to open it, then use **System Settings → Privacy & Security → Open Anyway**. [Apple's instructions](https://support.apple.com/en-us/102445).
- The interface is primarily Chinese. No model subscription or automatic updater is included.

## In this preview

- A project-based session sidebar with title search, pinning, renaming, archiving, and resume.
- A native composer with multiline editing, input methods, file attachments, and pasted images.
- Four interface modes, including the original CLI terminal and native conversations for Claude Code and Codex.
- Streaming replies, permission prompts, agent activity, task and change inspection, and diff comments.
- Git controls, PR/check status through `gh`, Claude worktrees, and Claude transcript backups.
- Onboarding detects installed CLIs and selects an available default.
- A bilingual repository guide, installation troubleshooting, contributor guidance, and repeatable packaging.

## Known limits

New Codex native conversations may disappear from Cove after closing with the tested CLI version; see [#5](https://github.com/huyanxius/Cove/issues/5).

Antigravity is experimental. Its conversation mode does not support approvals, interruption, or resumed history. CLI-only panels require a terminal mode. Usage information varies by CLI; API-rate estimates are not subscription charges. Removing a Codex rollout can leave a stale entry in the CLI's own index.

See [installation help](https://github.com/huyanxius/Cove/blob/main/docs/INSTALL.md) and [known limitations](https://github.com/huyanxius/Cove/blob/main/docs/KNOWN_LIMITATIONS.md). Verify downloads using `SHA256SUMS.txt`. Report reproducible issues with your app, CLI and macOS versions.
