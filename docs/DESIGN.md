# Cove 视觉语言

基调取自 Claude 原生界面：暖纸色底、衬线标题、克制的留白；把 Claude 的陶土橙换成港湾蓝。像素复古只落在**信息本身**上——状态点、进度格、图标——不做装饰性像素边框或复古字体正文。判断标准：删掉一个像素元素后信息量变少，它才配留下。

## 色彩

只有一个强调色。状态色里只有「等你」允许用暖色，因为那是唯一需要把人拉回来的状态。

| Token | Light | Dark | 用途 |
| --- | --- | --- | --- |
| `canvas` | `#F6F5F1` | `#15181C` | 窗口底色，暖纸 |
| `sidebar` | `#EEEDE7` | `#1A1E23` | 侧栏 |
| `surface` | `#FFFFFF` | `#1E2329` | 终端、输入框、卡片 |
| `hairline` | `#E2DFD7` | `#2B3138` | 1px 分隔线 |
| `ink` | `#1D2530` | `#E6E4DE` | 正文 |
| `inkMuted` | `#6D6A63` | `#9A968D` | 次要文字 |
| `harbor` | `#2E5E8C` | `#7EA7D0` | 唯一强调色：选中、运行中、链接 |

## 字体

- 标题与会话名：系统衬线（New York），人文感来自这里。
- 界面文字：SF Pro。
- 终端、diff、路径、状态条数值：SF Mono。
- 分组标签：SF Mono 10pt 大写、字距 +0.8，这是像素味的主要出口。

## 像素元素

- 状态点：4×4pt 方块，不用圆点。运行中在两格之间步进（`▖▘▝▗` 的节奏，0.25s 一帧），不用平滑动画。
- 任务进度：一排 6×6pt 方格，完成填实、进行中描边、待办留空。
- App 图标：16×16 像素网格，深港湾蓝底，暖纸色 C 形海湾，湾口一枚终端光标方块——海湾是 Cove，C 是 Claude，光标是 CLI。

## 版式

- 三栏：侧栏 240pt、中栏自适应、检查器 300pt，可折叠。
- 所有圆角 6pt；卡片不加阴影，只用 hairline。
- 间距以 4pt 为单位。
